# 研究日志

在这里记录真实的研究进度，不追求每天写很多。每条记录包含日期、做了什么、证据/文件、阻塞点和下一步。

建议结构：

- `papers/`：从 [`../templates/paper_note.md`](../templates/paper_note.md) 复制的逐篇阅读卡；
- `experiments/`：从 [`../templates/experiment_log.md`](../templates/experiment_log.md) 复制的实验记录；
- `weekly/`：每周小结，记录阶段门是否通过、问题是否需要缩小。

不要把模型权重、原始大数据、API 密钥、个人数据或大体积运行缓存提交进 Git。
